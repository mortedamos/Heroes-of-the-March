# Music

Drop `.mp3` files here. Only use music you have the rights to: this folder
will be public once the game is on GitHub Pages.

- `hero_selection.mp3` loops on the menu, the hero draft and the opening
  companion phase.
- When the normal rounds begin, the game starts on a random track from
  `TRACKS` in `src/client/audio/Music.ts` and plays that list in order,
  looping. Add a new playlist file's name to that list.
